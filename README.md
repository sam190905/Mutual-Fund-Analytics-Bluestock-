# Bluestock Mutual Fund Analytics

End-to-end mutual fund analytics capstone project for Bluestock Fintech. The project ingests Indian mutual fund datasets, cleans and validates them, loads them into a SQLite star schema, prepares Power BI-ready tables, and produces exploratory, performance, risk, portfolio, and investor behavior analytics.

## Project Overview

This project analyzes mutual fund performance and industry behavior across NAV history, AUM, SIP inflows, fund-house metrics, investor transactions, portfolio holdings, benchmark indices, and scheme-level risk/return data.

Key outcomes include:

- Cleaned and validated CSV datasets
- SQLite database with dimensional and fact tables
- SQL analytics queries for AUM, SIP trends, transactions, fund rankings, and performance
- Power BI-ready flat files
- Power BI dashboard file
- Jupyter notebooks for ingestion, EDA, performance analytics, and advanced analytics
- Generated reports, charts, and final PDF outputs
- Simple CLI fund recommender based on risk appetite and Sharpe ratio

## Datasets

The project uses 10 core CSV datasets:

| File | Purpose |
|---|---|
| `01_fund_master.csv` | Fund metadata, AMC, category, plan, benchmark, expense ratio, SIP/lumpsum minimums |
| `02_nav_history.csv` | Daily NAV history by AMFI scheme code |
| `03_aum_by_fund_house.csv` | Quarterly AUM by fund house |
| `04_monthly_sip_inflows.csv` | Monthly SIP inflows and active SIP account metrics |
| `05_category_inflows.csv` | Monthly net inflows by fund category |
| `06_industry_folio_count.csv` | Industry folio counts by segment |
| `07_scheme_performance.csv` | Scheme-level returns, alpha, beta, Sharpe, Sortino, drawdown, AUM, rating |
| `08_investor_transactions.csv` | Investor-level SIP, lumpsum, and redemption transactions |
| `09_portfolio_holdings.csv` | Fund portfolio holdings, sector weights, and market values |
| `10_benchmark_indices.csv` | Benchmark index close values |

See `data_dictionary.md` for full column definitions and examples.

## How To Run

Run the scripts in this order:

```bash
python scripts/data_ingestion.py
python scripts/validate_amfi_codes.py
python scripts/data_cleaning.py
python scripts/load_database.py
python scripts/powerbi_prep.py
```

Optional live NAV fetch:

```bash
python scripts/live_nav_fetch.py
```

Optional fund recommender:

```bash
python scripts/recommender.py Low
python scripts/recommender.py Moderate
python scripts/recommender.py High
```

## Pipeline

1. `data_ingestion.py` inspects raw CSV files, prints shapes, dtypes, heads, and basic anomaly checks.
2. `validate_amfi_codes.py` compares AMFI codes between fund master and NAV history and writes a data quality report.
3. `data_cleaning.py` cleans NAV history, investor transactions, scheme performance data, and copies remaining datasets to `data/processed/`.
4. `load_database.py` applies `sql/schema.sql`, creates the SQLite database, and loads cleaned datasets into star-schema tables.
5. `powerbi_prep.py` creates Power BI-ready flat files in `data/powerbi/`.
6. Notebooks generate EDA charts, performance metrics, risk analytics, scorecards, and advanced reports.

## Database Model

The SQLite database uses a star-schema design:

- Dimensions: `dim_fund`, `dim_date`
- Facts: `fact_nav`, `fact_transactions`, `fact_performance`, `fact_aum`, `fact_sip_industry`, `fact_category_inflows`, `fact_folio_count`, `fact_portfolio`, `fact_benchmark`

## Notes

- The project folder name currently includes a trailing space: `Mutual Fund Analytics `. Quote the folder name in shell commands.
- The active Python scripts are in `scripts/`.
- `live_nav_fetch.py` requires internet access because it calls `https://api.mfapi.in/mf/{scheme_code}`.
